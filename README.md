# Kakao-Tech-Bootcamp_Cloud-Native-Course

1주차 JAVA 1 과제 회고

- 과제를 받았을 때
  CLI 프로그램 로직과 스레드를 활용하는 것에 초점을 맞추었고, 만들고자 하는 로직에 클래스들을 억지로 끼워맞추려 하다보니 상속 관계를 고려한 클래스 다이어그램을 그리는 것이 어려웠다.
  이에 charlie가 상속 관계에 대해 제대로 알고있지 않은것 같다고 하시면서 예를 들어 설명해주셨다.
  CLI 프로그램을 만들기 전에 피드백을 받아 다행히 아이디어를 바꾸어 적절한 상속관계를 설정할 수 있었다.

- 코드 작성 과정
  로직을 설계할 당시에는 여러 디테일과 예외처리, 스레드를 다양하게 활용할 방법을 구상하였다. 하지만 구현을 해보니 6개의 클래스와 2개의 인터페이스를 작성하는 것에 많은 시간이 들었고, 더 필요한 메서드, 필요없는 클래스 변수들이 생겨나 클래스 다이어그램도 여러번 고쳤다.
  또, 생성형 AI를 사용하지 말자는 다짐을 가지고 코드를 작성하니 중간중간 정말 간단한 문법이 헷갈리는게 있어 찾아보는 시간도 있었다.
  결국에는 로직을 간단하게 바꾸었고, 실제 완성 코드를 짜는 시간보다 수정하는 시간이 훨씬 많이 걸린다는 것을 깨달았다.

- 결론
  과제의 목적을 파악하는 것이 첫번째로 할 일이고, 과제 수행 중간에 charlie에게 피드백을 받으며 방향성을 바로잡는 것이 중요하다.
  앞으로 어려운 과제가 주어져 불가피하게 생성형 AI의 도움을 받을 수는 있겠지만, 내가 스스로 해결할 수 있는 문제에 대해서는 시간이 걸리더라도 부딪혀볼 것이다.
  하지만 도움을 받았다면 훨씬 더 좋은 퀄리티의 프로그램을 짤 수 있었다고 생각해 아쉬운 마음이 들기는 하다..
